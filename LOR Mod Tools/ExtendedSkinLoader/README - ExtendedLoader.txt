Extended Loader is a plugin that allows a number of normally inaccessible (to external skins) features to be loaded from XML.
A more user-friendly skin editor for handling these extended features will be made later.

NOTE 1: DO NOT COPY THE EXAMPLE FOLDER INTO YOUR MOD, USE IT AS A REFERENCE.
NOTE 2: LOADING FACE ELEMENTS FROM MOD SKINS IS NOT COMPATIBLE WITH UGUARDIAN'S S-MOTION LOADER! (only in the same mod - there is no problem if another mod has it)
        REMOVE S-MOTION LOADER IF YOUR MOD IS USING FACE ELEMENTS (extended loader loads all available motions for extended skins anyway)

Features that are not included in the example (due to not being skin XML features):
1) Optimizes skin loading in the menus by only loading the default sprites that are displayed. Note that this can cause longer loading times when entering combat for the first time (due to the rest of sprites being loaded then).
