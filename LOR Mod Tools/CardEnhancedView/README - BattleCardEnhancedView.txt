This plugin allows viewing an arbitrary number of pages (more than the default 10) in normal hand and personal/EGO hand.
To facilitate easier page picking in such enlarged configurations, it also modifies the rotation of pages in hand (as the default rotation makes other pages to the left obscure the edge of the visible part).

Additionally, page zooming mechanism is added (to read small text easier), controlled by mouse wheel scrolling.
This mechanism will affect the last opened page in combat, whether in hand or slotted in Speed dice.
If you want a card UI to not assume the "currently zoomed" role (for example, due to only being a secondary preview card attached to original), use CardViewControls.AddIgnoredCard.
