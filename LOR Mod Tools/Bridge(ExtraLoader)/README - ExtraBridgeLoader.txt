This plugin is designed to work with BaseBridge to conveniently load entities that aren't normally supported by standard Ruina mod loader,
such as gifts (battle symbols), emotion cards (abnormality pages), floor ego cards and combat formations, 
all internally indexed (and accessible via BaseBridge) by compatibility-friendly LorId ids instead of compatibility-risky int ids.
It also allows loading some other additional data that is normally restricted by the default loader's data model
(custom options and categories in pages, custom floors in "only" and "exclude" lists for stages, modded exclusive pages,
passive innertypes that are "copied" from existing passives or "named" by string values instead of using compatibility-risky int ids again).
