This is a simple utility mod that lets Instance (also known as "On Play" Range) Combat Pages be played without unslotting
any non-Instance pages already slotted into the same Speed Die.

This also fixes the bug present in an older mod with the same intended functionality,
where Instance pages could be played for free if the user did not have enough Light, but would have enough if the current page was unslotted
(due to the not-unslotted page's cost still being accounted for as available Light, 
even despite it not being unslotted and the Light consequently not being actually made available).
