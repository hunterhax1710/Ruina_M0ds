This is a utility for handling receptions on the main invitation map, as well as some other features that are normally only used by specific receptions 
(such as Reverberation Ensemble using a custom reward logic instead of dropping burnable books).

For an example of configuring TimelineUtil with XMLs, check out StageModTimelineInfo_Example.xml
(the actual configuration file should be called StageModTimelineInfo.xml and be placed in the root folder of your mod - NOT in Assemblies!).
For the general reference on positions of original map elements, refer to StageModTimelineInfo_BasicCoordinates.xml.
For attaching more custom listeners to map-rendering events, read the documentation (TimelineUtil.xml).
