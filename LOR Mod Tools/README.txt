ALL TOOLS ARE DEPENDENT ON 0HARMONY. It is located in a separate folder to avoid wasting space (as it takes more than all other dlls combined, except 1FrameworkPriorityLoader).
Any other direct dependencies are already included in corresponding folders, so you just need to copy the tools you need + 0Harmony.
Note that for 1FrameworkPriorityLoader (and tools dependent on it) a game restart may be required after the first installation - the user will be informed.
All files should be placed into your mod's Assemblies folder, unless specified otherwise by a specific tool's README (as guides/examples for congifurable tools tend to be).

All dlls with public methods are documented (both as xml and inside dll).
All tool folders include more specific READMEs for the tool in question.
